# 📱 Mobile Price Prediction using Probability and Statistical Analysis

## 📌 Project Overview

This project focuses on analyzing smartphone specifications and understanding their relationship with mobile phone prices in the Indian market.

The project uses probability, statistical analysis, data visualization, and machine learning techniques to explore smartphone data and predict mobile prices based on their specifications.

## 🎯 Project Objectives

- Understand and analyze smartphone specifications.
- Study the relationship between smartphone features and prices.
- Apply statistical methods to summarize and interpret data.
- Visualize important patterns and distributions.
- Build a machine learning model to predict smartphone prices.
- Evaluate the performance of the prediction model.

## 📂 Dataset Description

The dataset is collected from Kaggle.

**Dataset Name:** Smartphone Specifications and Prices in India

**Author:** Shruti Ambekar

**Dataset Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/shrutiambekar/smartphone-specifications-and-prices-in-india)

The dataset contains smartphone information such as:

- Model
- Price
- Rating
- SIM Type
- Processor
- RAM
- Battery
- Display
- Camera
- Memory Card Support
- Operating System

## 📊 Project Methodology

The project will follow these major steps:

1. Data Collection
2. Data Understanding

4. Exploratory Data Analysis (EDA)

## 📈 Statistical Analysis

The project will explore statistical concepts such as:

- Mean, Median and Mode
- Variance and Standard Deviation
- Probability and Distributions
- Correlation Analysis
- Relationship between smartphone specifications and prices

## 🤖 Machine Learning

Regression techniques will be explored to predict smartphone prices using relevant smartphone specifications.

Model performance will be evaluated using suitable regression metrics.

## 📌 Expected Outcome

The project aims to identify meaningful patterns in smartphone pricing and develop a model that can estimate smartphone prices based on their specifications.
